## ACTUAL DATA LOCATION

### Python Scripts That Create Working Data

The real database with working credentials is created by these Python scripts:

1. **`backend/setup_complete_system.py`** MAIN SETUP SCRIPT
   - Creates all tables from scratch
   - Populates 300 students
   - Creates 5 faculty members
   - Generates marks, attendance, alerts
   - **This is the primary script used**

2. **`backend/populate_data.py`** (Alternative)
   - Similar to setup_complete_system.py
   - Populates data without dropping tables

3. **`backend/generate_data.py`** (Old version)
   - Creates 150 students (5 classes: 2Q11-2Q15)
   - Different class naming convention
