# Download Oracle Database XE - Step by Step

## 🎯 What You Need to Download

**Oracle Database 21c Express Edition (XE)**
- Size: ~2.5 GB
- Free to use
- Perfect for development

## 📥 Download Steps

### Step 1: Go to Oracle Website

Open your browser and go to:
```
https://www.oracle.com/database/technologies/xe-downloads.html
```

Or search Google for: "Oracle Database XE download"

### Step 2: Find the Windows Version

Look for:
```
Oracle Database 21c Express Edition for Windows x64
```

File name: `OracleXE213_Win64.zip`

### Step 3: Sign In or Create Account

You'll need a free Oracle account:

**If you don't have an account:**
1. Click "Create Account"
2. Fill in:
   - Email address
   - Password
   - Country
   - Accept terms
3. Verify your email
4. Sign in

**If you have an account:**
- Just sign in with your credentials

### Step 4: Download the File

1. Click the download link
2. Accept the license agreement
3. Click "Download OracleXE213_Win64.zip"
4. Save to your Downloads folder
5. Wait for download (2.5 GB - may take 10-30 minutes)

## 🆘 Download Problems?

### Slow download speed?
- Try downloading during off-peak hours
- Use a download manager (like Internet Download Manager)
- Check your internet connection

### Can't create Oracle account?
- Use a different email address
- Check spam folder for verification email
- Try a different browser

### Download keeps failing?
- Clear browser cache
- Disable VPN if using one
- Try a different browser (Chrome, Firefox, Edge)

### File corrupted after download?
- Check file size (should be ~2.5 GB)
- Re-download the file
- Verify checksum if provided
