🔧 CORS Configuration Test

Test Backend Connection

This will test if CORS is properly configured between frontend (port 8000) and backend (port 5000).

Instructions

  1. Make sure backend is running: cd backend && python app.py
  2. Make sure frontend is running: cd frontend && python -m http.server 8000
  3. Open this page at: http://localhost:8000/TEST_CORS.html
  4. Click "Test CORS" button above
