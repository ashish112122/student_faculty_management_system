# 🎯 How to Run Frontend Every Time After Opening Kiro

## The Easiest Way (3 Seconds!)

### Step 1: Find this file in your project folder
```
START_ALL.bat
```

### Step 2: Double-click it
That's it! Done! 🎉

---

## What Happens Automatically

1. ✅ Backend starts on port 5000
2. ✅ Frontend starts on port 8000
3. ✅ Browser opens with login page
4. ✅ System ready to use!

---

## Alternative: Frontend Only

If you only want to start the frontend (backend already running):

**Double-click:**
```
START_FRONTEND.bat
```

**Then open in browser:**
```
http://localhost:8000/login_test.html
```

---

## Want a Desktop Shortcut?

**Double-click:**
```
CREATE_DESKTOP_SHORTCUT.bat
```

This creates a shortcut on your desktop called "Start Student System"

Now you can start everything from your desktop! 🚀

---

## Quick Reference

| File | What It Does |
|------|-------------|
| `START_ALL.bat` | Starts everything (backend + frontend + browser) |
| `START_FRONTEND.bat` | Starts only frontend server |
| `START_BACKEND.bat` | Starts only backend server |
| `CREATE_DESKTOP_SHORTCUT.bat` | Creates desktop shortcut |

**Startup folder location:**
```
C:\Users\vansh\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup
```

Just create a shortcut to `START_ALL.bat` and put it there.
