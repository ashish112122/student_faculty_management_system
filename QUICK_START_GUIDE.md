# 🚀 QUICK START - Every Time You Open Kiro

## Option 1: Start Everything at Once (RECOMMENDED)

Just **double-click** this file:
```
START_ALL.bat
```

This will:
- ✅ Start Backend (Port 5000)
- ✅ Start Frontend (Port 8000)
- ✅ Open login page in browser automatically

**That's it!** Everything runs automatically.

---

## Option 2: Start Frontend Only

If backend is already running and you only need frontend:

**Double-click:**
```
START_FRONTEND.bat
```

Then open in browser:
```
http://localhost:8000/login_test.html
```

---

## Option 3: Start Backend Only

If you only need to restart backend:

**Double-click:**
```
START_BACKEND.bat
```
